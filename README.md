# 🛡️ ClarityLegal

> Decode the fine print before it decodes you.

ClarityLegal is a Chrome extension that analyzes Terms & Conditions, privacy policies, and other legal documents on any webpage — instantly surfacing the clauses that actually matter so you never sign away your rights blindly again.

---

## ✨ Features

- 🧩 **One-click analysis** — analyze any T&C page directly from your browser
- ⚠️ **Risk detection** — flags clauses around data sharing, auto-renewal, liability waivers, and other red flags
- 🧠 **Plain-language summaries** — turns dense legal jargon into clear, human-readable insights
- 📄 **Lightweight & fast** — minimal footprint, runs directly in-browser

---

## 🛠️ Tech Stack

| Layer | Tech |
|---|---|
| 🧩 Extension | Chrome Extension (Manifest V3) |
| 🎨 UI | HTML, CSS |
| ⚙️ Logic | Vanilla JavaScript (`content.js`, `popup.js`) |

---

## 🚀 Installation

1. Clone or download this repository
   ```bash
   git clone https://github.com/PiyushMaurya6074/claritylegal-extension.git
   ```
2. Open `chrome://extensions` in Chrome
3. Enable **Developer mode** (top-right toggle)
4. Click **Load unpacked**
5. Select the `claritylegal-extension` folder
6. The ClarityLegal icon will appear in your toolbar 🎉

---

## 📖 Usage

1. 📌 Visit any webpage with Terms & Conditions or a privacy policy
2. 🖱️ Click the ClarityLegal icon in your Chrome toolbar
3. ⚡ Click **Analyze** in the popup
4. 🧾 Review the risk summary and flagged clauses
